API de precios para agentes de IA

Precios de referencia de construcción en España, para programas y asistentes de inteligencia artificial.

¿Eres una persona? Esta página es para programas. Para calcular un presupuesto usa el gestor de presupuestos o la calculadora con IA, que son gratuitos, o pídenos presupuesto en el 607 444 903.

Qué ofrece

Acceso a 63.447 partidas de obra con código BC3 (BCEXTREM 2026 de la Junta de Extremadura, BCCA de la Junta de Andalucía y licitaciones públicas), recopiladas por ObraTudela. Sin registro ni claves: la búsqueda es gratuita y los precios se pagan por uso con el protocolo abierto x402 (USDC en la red Base).

ServicioPrecioQué devuelve
GET /api/buscar?q=textoGratisPartidas que encajan con el texto: código BC3, unidad y descripción.
GET /api/precio?cod=CODIGO0,01 $Precio de referencia en euros de una partida.
POST /api/oferta0,50 $Una petición de oferta de hasta 100 líneas con precio, importe y total.

Si el código no existe o no se encuentra ninguna partida, no se cobra.

Modelos 3D: bicicleta de cenital.org

La misma API da acceso a la bicicleta de carretera en 3D de cenital.org: 113 piezas con su STL, plano PDF y archivo de SolidWorks, con licencia libre. Los archivos se descargan gratis en la web; la API da los datos ya calculados para agentes.

ServicioPrecioQué devuelve
GET /api/piezas?q=textoGratisCatálogo de piezas: id, nombre, conjunto y medidas.
GET /api/pieza?id=ID0,01 $Ficha técnica: medidas, volumen, superficie, peso en acero, aluminio, titanio, carbono y PLA, si cabe en una impresora de 256 mm y enlaces a STL, PDF y SolidWorks.
GET /api/imprimir?id=ID&material=PLA&relleno=200,05 $Cálculo de impresión 3D: gramos y metros de filamento, horas y coste aproximados (PLA, PETG, ABS o TPU).

Cómo se usa

  1. Buscar el código (gratis): 
    GET https://api.cenital.org/api/buscar?q=contenedor escombros 8 m3
  2. Pedir el precio. La API responde 402 Payment Required con la cabecera PAYMENT-REQUIRED; el agente firma el pago y repite la petición con PAYMENT-SIGNATURE: 
    GET https://api.cenital.org/api/precio?cod=M12O013
  3. O rellenar una oferta completa: 
    POST https://api.cenital.org/api/oferta

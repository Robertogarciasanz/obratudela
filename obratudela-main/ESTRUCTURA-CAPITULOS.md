# 📋 Estructura Jerárquica de Presupuestos por Oficios

**ObraTudela - Base de Precios BCEXTREM 2026**

## 🎯 Objetivo

Este documento describe la organización jerárquica de partidas de obra por **capítulos lógicos según oficios y fases constructivas**, facilitando la elaboración de presupuestos ordenados y profesionales.

## 🔧 Uso en Aplicaciones

### **Frontend (presupuesto_v2.html)**

El sistema de navegación lateral organiza las partidas por capítulos:

```javascript
const CAPITULOS = [
  { num: '01', name: 'Demoliciones...', keys: ['DEMOLICION', 'R0'], icon: '🔨' },
  { num: '02', name: 'Movimiento de Tierras...', keys: ['CARGA'], icon: '⛏️' },
  // ...
];
```

**Características:**
- ✅ Navegación visual con iconos y colores
- ✅ Contador de partidas por capítulo
- ✅ Subcapítulos expandibles
- ✅ Búsqueda integrada dentro de cada capítulo

---

### **Backend API (admin-server.js)**

El endpoint QUERY soporta filtrado por capítulo:

```bash
curl -X QUERY "https://www.obratudela.com/api/precios/search" \
  -H "Content-Type: application/json" \
  -d '{
    "filters": {
      "capitulo": "01",
      "precio": {"min": 50, "max": 500}
    }
  }'
```

**Mapeo interno:**
```javascript
const CAPITULOS_MAP = {
  '01': ['DEMOLICION', 'R0'],
  '02': ['CARGA'],
  '03': ['E1', 'A0'],
  // ...
};
```

La API convierte automáticamente el número de capítulo a las categorías BCEXTREM correspondientes.

## 📐 Estructura de Partidas

Cada partida incluye:

| Campo | Descripción | Ejemplo |
|-------|-------------|---------|
| **cod** | Código único de partida | `A01MA010` |
| **uni** | Unidad de medida | `m3`, `m2`, `ml`, `ud`, `%` |
| **res** | Descripción resumida | `MORTERO CEMENTO M-20` |
| **desc** | Descripción completa | `Mortero de cemento CEM II/B-M 32,5 R...` |
| **precio** | Precio unitario en euros | `130.98` |
| **categoria** | Categoría BCEXTREM | `A0`, `C0`, `E1`, etc. |

## ⚠️ Notas Importantes

1. **Mapeo parcial:** Actualmente solo se han mapeado las categorías BCEXTREM existentes en el archivo `precios.json`. Los capítulos sin categorías asignadas (06, 07, 08, 09, 10) están preparados para futuras ampliaciones.

4. **Búsqueda combinada:** Se puede buscar tanto por capítulo como por categoría BCEXTREM directamente.
